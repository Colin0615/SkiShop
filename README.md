3. **Pages**: Copy content from `content/pages/` into Shopify page editor
4. **TikTok**: Follow the content calendar in `content/tiktok/content-calendar.md`

- All prices include VAT (EU legal requirement)
- IOSS applies only to orders ≤€150 intrinsic value
- Textile labels must be in target country language (French for France)
- GPSR requires EU responsible person — your Irish company fulfills this
